The question.

Researchers at Palmer Station, Antarctica measured 344 penguins of three species. Our model answers one yes/no question about each bird.

Object
One adult penguin, measured in 2007–2009
Target
is_adelie: 1 = Adelie, 0 = Chinstrap or Gentoo
Features
Bill length, bill depth, flipper length (mm)
Data
palmerpenguins: 344 rows, real field labels, CC0 licence
Task
Supervised binary classification

Flipper length is the third measurement: the wing, from body to tip.

The data.

Before training anything, we checked the balance, the gaps and the shape of every feature.

Class balance

Class 1: 152 Adelie (44%)Class 0: 192 others (56%)

Only slightly unbalanced, so no resampling. We still split with stratify and score with F1, which focuses on the Adelie class.

Missing readings

2 penguins have no measurements at all: row 3 (Adelie) and row 271 (Gentoo). These are real gaps in the field data.
We keep them. Inside the pipeline a median imputer fills the gaps, using medians learned from training rows only. No fake gaps were added.

Bill length

The clearest signal: Adelie average mm vs mm for the others. Overlap only between about 41 and 46 mm.

Bill depth

Adelie bills are deeper ( vs mm), but Chinstrap bills are just as deep, so depth alone is not enough.

Flipper length

Adelie flippers are shorter ( vs mm). Gentoo flippers are long; Chinstrap ones overlap with Adelie.

Length and depth together

Each dot is a penguin. Adelie penguins sit in their own group in the top-left corner: short and deep bills. Gentoo penguins have long, shallow bills; Chinstrap penguins have long, deep ones.

An almost straight line separates Adelie from the rest, so a linear model should already work well. The features use different scales (flipper about 200 mm, depth about 17 mm), so we standardize them.

Two models.

Split first, then let each pipeline learn only from the training penguins.

80/20 stratified split

275 train (44.4% Adelie)
69 test

The test penguins are locked away. Imputer and scaler never see them, so nothing leaks from the test set into training.

The two pipelines

Median imputer→Standard scaler→Logistic Regression
Median imputer→Standard scaler→Random Forest

Logistic Regression learns one weighted formula and turns it into a probability. Random Forest grows 150 trees (depth ≤ 6, at least 3 penguins per leaf) and lets them vote.

Cross-validation F1

Same 3 stratified folds, same F1 metric, training data only. Logistic Regression wins: mean 0.976 (SD 0.010) vs 0.962 (SD 0.019). It is also steadier from fold to fold.

Decide.

Which mistake costs more? Imagine a field team using the model in a census of Adelie penguins.

False negative

An Adelie is called "other". We under-count Adelie penguins.

False positive

A Chinstrap or Gentoo is called Adelie. We over-count them and could hide a real decline. For a census, this is the costlier error.

Our choice: 0.7

Going from 0.5 to 0.7 cuts false positives from 4 to 1 and costs one extra false negative. F1 even rises to 0.983.

Checked once on the test set: 0 false positives, 1 false negative (penguin 129).

If missing an Adelie were the costly error, for example an alert for a protected species, we would go the other way: at 0.3 recall is 1.000, but false positives grow to 9.

The verdict.

We used the open palmerpenguins dataset (real field labels, nothing simulated) to decide whether a penguin is an Adelie from three measurements. After an 80/20 stratified split and leakage-safe pipelines, Logistic Regression beat Random Forest on 3-fold cross-validation (F1 0.976 vs 0.962). On the untouched test set it reached F1 0.967 and ROC-AUC 0.999, with one false positive and one false negative. Bill length was the most influential feature, then bill depth. This is performance on one public benchmark, not a guarantee for other colonies or years.

Limitations

Only 344 penguins from 3 islands, measured in 2007–2009. Only three species exist in the data, so any other penguin would still be forced into "Adelie" or "other". With 69 test penguins, one mistake moves F1 by about 1.6 points.

Risks

Penguins from other colonies or years may look or be measured differently. All our mistakes happened between probabilities 0.4 and 0.6, so answers there should be double-checked. Importance is not cause and effect.

Improvement

Measure penguins from later years and other colonies and use them as a truly new test set. Also try body mass as a fourth feature and compare models with repeated cross-validation.
